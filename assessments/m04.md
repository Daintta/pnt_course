# Module 04 assessment: High-Accuracy and Augmented GNSS

## single
What is the core principle behind differential GNSS (DGNSS)?
- A second receiver on the same vehicle doubles the number of measurements.
* A receiver at a precisely surveyed location can estimate correlated errors and supply corrections to nearby users.
- Satellites transmit a second, more accurate signal for paying users.
- The user receiver averages its position over a long period.
> The reference station knows where it really is, so it can estimate errors that nearby users experience similarly.

## single
Why does a DGNSS correction become less useful as the user moves farther from the reference station?
- Corrections are encrypted by distance.
* Some errors, especially spatially varying atmospheric effects, decorrelate with distance.
- The reference station can only see satellites directly overhead.
- Radio links always fail beyond 1 km.
> Correlation between user and reference errors weakens with distance, so the correction becomes less representative.

## multi
Beyond an accuracy figure, which requirements may a correction-based architecture need?
* Correction update rate
* Maximum correction age and end-to-end latency
* Behaviour when corrections are lost
* Communications availability
- The colour of the reference station enclosure
> Corrections are time-sensitive and delivered over a link, so their timeliness and failure behaviour must be specified.

## single
Why is SBAS described as "not just more accurate GPS"?
- Because it only works for GLONASS.
* Because, for supported safety services, it provides integrity information enabling users to know whether to rely on the service within defined protection and alerting limits.
- Because it replaces the GNSS constellations entirely.
- Because it provides centimetre-level accuracy everywhere.
> SBAS provides corrections and integrity-related information. For safety-of-life use, the integrity role is especially important.

## match
Match each SBAS to its region.
- EGNOS = Europe
- WAAS = United States
- MSAS = Japan
- GAGAN = India
> SBAS performance and services vary by system and service definition, so engineers should consult the applicable documents.

## single
What makes carrier-phase measurements central to RTK?
- They are unambiguous from the moment of acquisition.
* They are extremely precise, and once the integer ambiguities are resolved they enable centimetre-level relative positioning.
- They remove the need for a reference station.
- They are immune to multipath.
> Carrier phase is precise but ambiguous. RTK resolves the integer ambiguities using simultaneous base and rover observations.

## single
An RTK receiver reports a "float" solution. What does this mean?
* The carrier ambiguities have not yet been reliably fixed to integers, so precision is generally poorer than a fixed solution.
- The receiver has full centimetre-level accuracy.
- The receiver has lost all satellites.
- The base station is floating on water.
> Fixed means the integer ambiguities are resolved and validated. Float means they are not, so performance is lower.

## truefalse
If a system is "RTK enabled", it is always delivering centimetre-level accuracy.
= false
> An RTK-capable system may not currently hold a fixed solution. Performance depends on ambiguity resolution, geometry, baseline, atmosphere, corrections and communications.

## single
What is a key consequence of increasing the RTK baseline length?
- Ambiguity resolution becomes easier.
* Errors at base and rover become less correlated, atmospheric differences grow and ambiguity resolution can become harder.
- The rover no longer needs corrections.
- Baseline length has no effect on RTK.
> Longer baselines weaken the correlated-error assumption. Network RTK exists partly to address this.

## match
Match each technique to its main source of strength.
- RTK = Spatially correlated measurements at a nearby reference
- PPP = Precise global satellite orbit and clock products plus detailed modelling at the user
- SBAS = Wide-area corrections and integrity information broadcast via geostationary satellites
- DGNSS = Code or range corrections from a known reference station
> Each technique solves a different problem with different dependencies; they are not simply rungs on an accuracy ladder.

## single
A mission requires 5 cm accuracy within 10 seconds of start-up. A PPP service eventually reaches 3 cm after a long convergence period. What is the correct assessment?
- It meets the requirement because 3 cm is better than 5 cm.
* It may not meet the requirement: accuracy and time-to-accuracy are separate requirements.
- PPP never reaches centimetre-level accuracy.
- Convergence time is irrelevant for high-accuracy systems.
> A system that eventually reaches the accuracy may still fail the mission if it cannot do so in the required time.

## truefalse
PPP-RTK, network RTK and SSR are standardised terms used identically by every provider.
= false
> Terminology varies. Ask what correction information is actually supplied and how the receiver uses it, rather than relying on the label.

## single
A high-accuracy system receives corrections over a mobile data network. Which statement best reflects the module's resilience lesson?
- Adding corrections always improves resilience because accuracy improves.
* The correction path becomes part of the PNT architecture, adding dependencies such as communications, processing and service credentials.
- Corrections cannot fail once the receiver has a fixed solution.
- Communications are outside the scope of PNT engineering.
> Improving accuracy can add dependencies. Better accuracy is not automatically better resilience.

## single
A supplier says "we use RTK, so our PNT is resilient". What is the best response?
- Agree, because RTK is the most accurate technique.
* The conclusion does not follow: RTK is a positioning technique, and resilience requires analysis of threats, failure modes, dependencies, detection, fallback and recovery.
- Agree, provided it is network RTK.
- Disagree, because RTK cannot be used in resilient systems.
> High accuracy does not prove integrity or resilience. A centimetre-level receiver can still be vulnerable to interference, spoofing or bad corrections.

## single
A safety-related aviation application is choosing an augmentation approach. What should drive the selection?
- The smallest possible accuracy figure on the datasheet.
* Integrity, alerting and defined service performance within the supported service area.
- Whichever technique has the shortest name.
- The cheapest receiver available.
> Surveying, autonomy and aviation can all use augmented GNSS, but their acceptance criteria differ. Never select from the accuracy figure alone.
