# Module 02 assessment: How GNSS Works

## match
Match each GNSS segment to its purpose.
- Space segment = Transmits ranging signals and navigation information from orbit
- Control segment = Monitors and manages the constellation and uploads orbit and clock information
- User segment = Receives and processes signals to produce PNT information
> A GNSS is more than satellites: space, control and user segments interact to deliver the service.

## single
From each useful satellite, what two things does a receiver fundamentally need?
- The satellite's serial number and its launch date
* An estimate of where the satellite was, and a measurement related to how far away it was
- The satellite's transmit power and the receiver's own position
- The almanac and a correction service subscription
> The navigation message helps provide satellite position; signal timing provides the range-related measurement.

EGNOS is a separate global navigation satellite constellation that can replace Galileo.
= false
> EGNOS is an augmentation system. It uses monitoring infrastructure and geostationary broadcasting to provide corrections and integrity-related information for supported GNSS services.

## single
Why does GNSS acquisition involve searching across frequency as well as code timing?
- Because each satellite changes its broadcast frequency every minute.
* Because relative motion between satellite and receiver creates Doppler shift.
- Because the receiver clock runs at a different frequency from the almanac.
- Because frequency search removes multipath.
> Acquisition searches across possible code timing and frequency offset. Relative motion causes Doppler shift, so the frequency must be searched too.

## single
What is the difference between acquisition and tracking?
* Acquisition is the initial search to find and identify a signal; tracking keeps the local code and carrier aligned so measurements continue.
- Acquisition decodes navigation data; tracking computes the position.
- Acquisition happens in the control segment; tracking happens in the receiver.
- They are two names for the same process.
> Acquisition finds the signal. Tracking maintains lock as conditions change so measurements and data can continue to be extracted.

## single
Why is the basic GNSS code measurement called a "pseudorange"?
- Because it is measured to a pseudo-random point near the satellite.
* Because it is an apparent range derived from signal timing that includes clock differences and other effects, not the exact geometric distance.
- Because it is only an estimate made from the almanac.
- Because it is always longer than the true range by exactly the speed of light.
> Range is the geometric distance. Pseudorange is the apparent range from signal travel time, including clock offsets and propagation and equipment effects.

## multi
Which are the four unknowns solved in a conventional three-dimensional GNSS solution?
* X position
* Y position
* Z position
* Receiver clock bias
- Satellite transmit power
> Three spatial coordinates plus receiver clock bias, which is why at least four suitable measurements are normally needed.

## match
Match each type of navigation data to what it provides.
- Ephemeris = Precise orbit information for the transmitting satellite during its validity period
- Almanac = Coarser orbit and status information covering the wider constellation
- Health / service information = Indicates whether particular satellite information or signals should be used
- Satellite clock information = Allows correction for predicted satellite clock offset
> Ephemeris is precise and satellite-specific; the almanac is a coarse constellation directory that supports acquisition.

## single
A receiver knows from the almanac that a satellite is overhead but has not yet decoded that satellite's ephemeris. What is the most accurate statement?
- It can use that satellite immediately at full accuracy.
* It knows roughly where to look, but needs sufficiently accurate orbit information before the range can support a good position.
- The almanac and ephemeris are interchangeable.
- It needs the control segment to transmit its position to the satellite.
> Knowing a satellite exists is not enough. Turning a range into a position needs accurate satellite position at the transmission time.

## truefalse
Two systems can each produce internally accurate positions yet still disagree about where an object is.
= true
> Different reference frames, datums, transformations or height conventions can make accurate positions disagree numerically.

## single
A GNSS-derived height is fed into a system that expects heights above mean sea level. What is the main engineering concern?
- GNSS cannot measure height at all.
* Ellipsoidal height from GNSS is not automatically the same as an orthometric or mean-sea-level-style height.
- Heights are always identical whichever reference is used.
- The concern only applies to underwater systems.
> Height reference must be explicit. Interfaces should define the frame, representation, height reference and any required transformation.

## order
Put these steps of producing a GNSS solution in the order described in the module.
1. Acquire and track signals from satellites in view
2. Decode the navigation data needed for the solution
3. Determine satellite positions and account for satellite clock information
4. Measure pseudoranges from signal timing
5. Solve for receiver position and clock bias
6. Output Position, Velocity and Time to the application
> The system-level flow runs from acquisition through data decoding, satellite position, measurements and solution to PVT output.

## single
Four satellites are available but are clustered in one small part of the sky. Which statement is correct?
- Four satellites always give the same quality as any other four.
* Geometry matters: clustered satellites give poorer geometry than well-distributed ones, even with the same count.
- Clustered satellites give better accuracy because their signals are similar.
- The receiver cannot compute any solution with clustered satellites.
> Satellite count alone does not determine quality. Geometry and measurement quality also matter, developed through DOP in Module 3.

## single

- Treat the receiver as a black box that outputs coordinates.
