## single
A PNT assessment of a regional electricity network finds that no assets move and nobody navigates. What is the most appropriate conclusion?
- The network has no PNT dependency and can be excluded from the review.
* The network may still be critically PNT-dependent because it can rely on synchronised time.
- The network only depends on PNT if it uses GPS receivers for asset tracking.
- Timing dependencies only matter for navigation systems.
> Timing is a PNT capability in its own right. Electricity infrastructure, telecommunications, finance and distributed computing can depend on synchronised time without navigating.

## single
A requirement states only that "the system shall provide position". According to the module, what should an engineer establish next?
- The brand of GNSS receiver to be procured.
- The number of constellations the receiver supports.
* The reference frame, dimensions, accuracy, update rate and operating environment the application needs.
- Whether latitude and longitude are displayed in degrees or radians.
> Position is not automatically latitude and longitude. The engineer needs the reference frame, dimensions, accuracy, update rate and operating environment before the requirement is meaningful.

## match
Match each PNT capability to the question it answers.
- Positioning = Where am I, or where is something?
- Navigation = Where am I going, and how do I get there?
- Timing = What time is it, and how accurately must systems agree on it?
> Positioning, navigation and timing are related but distinct capabilities with different engineering requirements.

## order
Put the stages of the first-order PNT chain in the correct order.
1. Source
2. Signal / measurement
3. Receiver / sensor
4. PNT solution
5. Application
> Source → Signal/Measurement → Receiver/Sensor → PNT Solution → Application. The model helps identify where dependencies and failure modes exist.

## single
A high-accuracy receiver is reporting as healthy, but the application's position quality has degraded. Which explanation is consistent with the PNT dependency chain?
- A healthy receiver guarantees that the whole chain is healthy.
* An upstream element, such as the correction service or the communications network delivering it, may have failed.
- The application must have a software fault because the receiver is healthy.
- Degradation can only come from the satellites themselves.
> Failure can occur anywhere along the dependency chain. A receiver may keep operating while its correction service or the network that delivers it is unavailable.

## truefalse
A receiver that is multi-constellation is, by definition, also multi-frequency.
= false
> Multi-constellation means using more than one satellite system; multi-frequency means using more than one signal band. A receiver can be one, the other, both or neither.

## single
Approximately how much range error corresponds to a timing error of one microsecond in GNSS ranging?
- About 30 centimetres
- About 3 metres
* About 300 metres
- About 30 kilometres
> Radio signals travel at roughly 300,000 km/s, so one microsecond equates to about 300 m. One nanosecond is roughly 30 cm.

## single
Why must a typical consumer GNSS receiver estimate its own clock bias?
- Because the satellites do not carry clocks.
* Because it does not carry a satellite-grade atomic clock, so its clock error is solved as part of the navigation solution.
- Because clock bias is needed only for timing applications, not positioning.
- Because the almanac does not contain time information.
> Consumer receivers lack atomic clocks. Receiver clock bias becomes the fourth unknown alongside X, Y and Z.

## match
Match each performance characteristic to its description.
- Accuracy = Closeness of a reported value to the true value
- Precision = Repeatability or tight grouping of repeated measurements
- Availability = Whether the required service is there when needed
- Continuity = Whether the service continues without unexpected interruption during the operation
- Integrity = The trust that can be placed in the information, including warning when it should not be used
> PNT performance is multi-dimensional. Accuracy alone does not describe whether a system is fit for purpose.

## single
A set of repeated position fixes is tightly grouped but consistently 12 m from the true location. How is this best described?
- Accurate but not precise
* Precise but not accurate
- Both accurate and precise
- High integrity
> Precision is repeatability; accuracy is closeness to truth. A result can be precise yet consistently wrong.

## single
Which failure is generally more dangerous from an integrity perspective?
- A receiver that clearly reports no position is available.
* A receiver that keeps outputting a convincing but incorrect position without warning.
- A receiver switched off for scheduled maintenance.
- A receiver with a slow start-up time.
> Downstream systems and operators may continue acting on convincing but wrong information. A clear loss of service is disruptive but visible.

## multi
A receiver uses GPS, Galileo and BeiDou. Which common-mode dependencies could still affect all three at once?
* A single shared antenna and cable
* A strong local RF interference source
* A shared power supply or processing unit
- The different national operators of each constellation
> Constellation diversity improves visibility, but shared RF paths, equipment and local interference can defeat all constellations together. Different operators do not remove these shared dependencies.

## multi
Which of these are useful first-order dependency questions for a PNT-dependent system?
* What happens if PNT remains available but becomes misleading?
* How quickly must degradation or erroneous information be detected?
* How long can the system continue in a degraded state?
- Which receiver vendor has the best-known brand?
> Engineering assessment focuses on required capability, consequences, detection time, degraded operation and evidence, not product names.

## truefalse
Redundancy, diversity and dissimilarity are synonyms; adding any of them guarantees resilience.
= false
> They are related but distinct. A resilient design asks whether alternative sources have genuinely different failure modes.

## single
A supplier says: "Our solution is resilient to spoofing." Which response best reflects how a PNT engineer should engage?
- Accept the claim because spoofing resilience is a listed product feature.
- Reject the claim because no system can be resilient to spoofing.
* Ask what evidence supports it, against which threat model, under what conditions, and what the system does when the threat is detected.
- Ask how many constellations the product supports.
> Good PNT conversations start with requirements, threat models and evidence rather than accepting feature claims.
